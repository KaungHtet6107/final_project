# Final project

## Emotion Detection Application

This project is an AI-based web application that detects emotions from a given text statement.

The application uses the Watson NLP Emotion Prediction service to identify five emotions:

- Anger
- Disgust
- Fear
- Joy
- Sadness

It also determines the dominant emotion, which is the emotion with the highest score.
